# BLUSH CLUB концепт-магазин крафтовых напитков

## функции
- каталог, категории, сортировка и поиск
- карточки товаров
- система заказов, оформление
- корзина: добавление, удаление, изменение количества, подсчет суммы
- избранное
- админ-панель
- просмотр статистики и изменение статуса
- сохранение данных и заказов в базе данных
- демо-подписка на рассылку
- возрастной экран
- адаптивная верстка и мобильная навигация
